# 수정주가 타임시리즈 — 설계 + 핸드오프

> **목표: 안정적인 수정주가 타임시리즈.** 안정적 = ① 정확(벤더 대비 검증) ② 근거 추적 가능
> (모든 조정에 거래소 실측 or 공시 rcept_no) ③ 자동 유지(신규 이벤트 자동 반영, 미해결은 조용히
> 틀리는 대신 flag/마스킹). 이 문서 하나로 다른 세션/PC가 이어받을 수 있게 쓴다.

## 1. 핵심 설계 — 추리에서 실측으로

수정주가 조정(권리락·배당락·분할·감자 재상장)의 **집행 주체는 거래소**다. KRX는 조정일 아침
기준가를 직접 바꿔 시장을 열고, 그 흔적이 일별시세의 `전일대비(CMPPREVDD_PRC)`에 남는다:

```
정상일:  전일종가 == 오늘종가 − 전일대비
조정일:  전일종가 != 오늘종가 − 전일대비   →  조정계수 = (종가−전일대비) ÷ 전일종가
```

날짜·크기 모두 거래소 공식값 → 발행가·배정비율 재계산 불필요. 검증(260702, 실측 6케이스):
대한항공 유증락 0.8362 / 한화솔루션 0.9693 / 셀트리온 주식배당락 5%·2% 정확 /
오리온홀딩스 인적분할 1/20.36 / SKT 분할+액면분할 1/5.80 — **벤더(DataGuide) 이탈률과 자릿수까지 일치**.

3축 구조:

| 축 | 테이블 | 역할 |
|---|---|---|
| 가격 (실측) | `krx_base_resets` (예정) | 조정일 + 계수의 원천 |
| 수량 (실측) | `krx_shares_ledger` | 교차검증 + 소각/CB 구분 + 신규상장·상폐 |
| 근거 (공시) | `dart_capital_events` 등 | 리셋의 이벤트 라벨 + rcept_no |

## 2.1 벤더 방법론 공식 확인 (FnGuide 회신, 260703)

FnGuide 문의 회신 요지 — **우리 기준가 리셋 방식이 벤더 현행 방법론과 정합함을 공식 확인**:

- **DG(데이터가이드) = 퀀티와이즈 동일 방식** (구DG와 차이는 개편 때문).
- **권리락류(주주배정 유증·무상증자·주식배당)**: 권리락 주가변동 반영 = 우리 기준가 리셋 실측과 동일. ✅
- **권리락 없는 이벤트(3자배정 유증·CB전환)**: 계수 미적용 — 우리도 리셋이 없어 자동 배제. ✅ (§3 ② 주석의 "올바름" 공식 확인)
- **액면변경(개편)**: ~~전일종가/기준가~~ → **변경 전/후 액면가 비율** 적용. 액면변경 기준가는 기계적(전일종가×비율)이라
  실측값과 거의 일치하나, **v3에서 액면변경 이벤트는 액면가 비율(KRX `stk_isu_base_info` PARVAL 추이)로
  크로스체크·치환** — 벤더 방법론과 자릿수까지 정렬.
- **시장이전(개편)**: 계수 **미적용**. → v3에서 KOSDAQ↔KOSPI **이전일에 잡힌 리셋은 계수 제외**(오탐 방지 규칙).
- **채점 주의**: 로컬 DG 덤프가 **구버전 DG 추출본이면** 액면변경·시장이전에서 정당한 불일치 발생 —
  이탈 분류 시 "구DG 방법론 차이" 카테고리 필수 (STOP 게이트 오판 방지).

## 3. 다음 실행 순서 (이어받는 사람은 여기부터)

```powershell
# ① 기준가 리셋 전수 스윕 — KRX ≈5,150콜 (키당 일 10,000 한도 · 스크립트 캡 9,000 · 재개 가능)
.\.venv\Scripts\python.exe scripts\krx_base_resets.py --sweep

# ② v3 계수 생성: krx_base_resets × 공시 라벨링(dart_capital_events·crDecsn·cmpDvDecsn·제목스캔)
#    - 리셋 계수는 실측 그대로, 공시는 event_type + evidence(rcept_no)만 부여
#    - 라벨 미확인 리셋 → confidence='unlabeled' (계수는 유효 — 거래소 실측이므로)
#    - 스핀오프: DataGuide 방식(소급 조정) 채택 결정됨. 단 spinoff_break flag는 유지
#      (분할 전 배수 비교는 여전히 무의미 — 시리즈 연속성과 분석 유효성은 별개)
#    - 소각(가격무변·주식수감소)은 리셋이 없으므로 자동 배제됨 — 올바름

# ③ 채점: DataGuide 덤프(로컬 보유, KOSPI200)와 대조 — ★참조 전용, 파이프라인 의존 금지★
#    게이트: clean 종목 최대오차 ≤1% 비율 95%+

# ④ 유지 통합: 주간 ingest에 리셋 --update + 원장 증분 + 신규 리셋 자동 라벨링
```

## 4. STOP 조건 (품질 게이트 — 우회 금지)

- **DG 채점 95% 미달 → 원인 규명 전 사용·배포 금지.** 이탈 종목은 건별 원인(리셋 누락/라벨 오류/
  DG 방법론 차이)을 분류해 문서화 후 재판정.
- `krx_stock_flags` 종목은 수정주가 소비 시 **경고 부착 또는 마스킹** — flag 무시한 소비 금지.
- KRX 키당 일 10,000콜 / DART 일 20,000콜·분당 910 — 스크립트 내장 캡 임의 해제 금지.
- DataGuide 데이터를 파이프라인 원천으로 사용 금지 (라이선스) — 채점·레퍼런스 전용.

## 6. 이력 요약 (왜 이 설계에 도달했나)

관측 휴리스틱(주식수 급변×시총연속)은 주간 해상도·정지 갭·소규모 이벤트·복합 주간에서 구조적으로
샌다 — v1(공시 크로스체크: high도 4.7% 오탐, medium 82% 오탐), v2(원장+공시 매칭: 1,751건)로
좁혔지만 유증 권리락처럼 "조정량을 우리가 계산해야 하는" 클래스는 남았다. 기준가 리셋은 그 계산을
거래소가 이미 끝낸 값을 읽는 것이므로 전 클래스가 실측으로 통일된다. (상세 판정 이력·패널 기록은
`krx_adj_factor`/`_v2`의 note·evidence 컬럼에 보존)
